## Findings to fix (from Jarvis's audit; site https://jev.gorock.sh)
1. No security headers. Add `next.config.ts` with `headers()` for all routes:
   `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`,
   `Referrer-Policy: strict-origin-when-cross-origin`,
   `Permissions-Policy: camera=(), microphone=(), geolocation=()`, and a CSP that
   works with this app WITHOUT breaking it: `default-src 'self'`; scripts/styles
   as Next 16 static pages actually need (verify in a real browser-less check: build,
   start, fetch pages, and confirm no inline script is blocked — if nonces are
   impractical for static pages, use the narrowest policy that works and say
   exactly what you allowed and why); `img-src 'self' data:`; `font-src` as used;
   `connect-src 'self'`; `frame-ancestors 'none'`; `base-uri 'self'`;
   `form-action 'self'`. Keep `/mcp` and `/api/v1/*` CORS behaviour unchanged.
2. `/research/%2e%2e%2fpackage.json` renders the not-found UI with HTTP 200.
   Unknown research slugs must return 404 (see `src/app/research/[slug]/page.tsx`,
   `src/lib/research-data.ts`; likely `dynamicParams = false` or `notFound()`).
   Check the same for claims/projects/patterns/ideas `[slug]` routes.
3. `src/components/document-reader.tsx` ~L43: the markdown `a` renderer passes
   `href` through unchecked. Allow only http(s), mailto, `/`-relative and `#`
   hrefs — reuse `safeHref` from `src/lib/format.ts` / `isSafeHttpUrl` in
   `src/processing/links.ts`; render plain text otherwise.
4. Fit-check headline etc. are model text: confirm they are only ever rendered
   as React text, and strip `<`/`>` control characters in `postValidate` clamps
   (`src/lib/fit-check.ts`) so the copy-as-markdown output cannot carry HTML.
5. Add tests in `test/security.test.ts` for 2–4 (pure functions / route handlers,
   no network) and one asserting the header set exported by next.config.
